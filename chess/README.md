# ChessMind

A chess app for playing and learning, in plain HTML and JavaScript with no build step. Its own engine runs in a Web Worker.

## Run it

```bash
python3 -m http.server 8000
```

Then open http://localhost:8000/chess/. (Opening `index.html` straight from disk also works, but the engine then runs on the main thread, so it is slower.)

## What's inside

**Placement match.** Your first game is against the *Adaptive Coach*. After each of your moves the engine measures how much winning chance the move gave away. It updates an estimate of your level and sets the bot to play at that level for its next move. When the game ends, that estimate, adjusted for the result, becomes your starting rating, and your learning path starts there.

**Play.** You can play bots from 250 to 2500:
- **Rated mode** changes your rating (Elo).
- **Coach mode** gives live feedback on every move (Best / Excellent / Good / Inaccuracy / Mistake / Blunder) with a plain-language reason, for example "It allows Nxf7, and you lose a piece. Better was Bd3". It also has hints, a threat detector ("what would my opponent play if it were their move?"), takebacks and an eval bar.

**Game report.** Every game, or any PGN you paste in, gets a move-by-move review with:
- accuracy for each side, and an estimated performance rating
- an evaluation graph
- book moves recognized from the openings library
- your key mistakes, which you can add to a spaced-repetition **mistakes deck**

**Learn: 526 lessons**

| Category | What it covers |
| --- | --- |
| Rules & Basics | The board, every piece (with "collect the pawns" mini-games), check, mate, stalemate, castling, en passant, notation, piece values, hanging pieces, how to think (checks, captures, threats) |
| Opening Principles | Center, development, castling, early queen moves, f7, gambits |
| Checkmate Patterns | Back rank, smothered, Philidor's legacy, Anastasia, Arabian, Boden, epaulette, Opera, Lolli, Damiano, Greco, Morphy, Anderssen, corner, Blackburne, pawn mates, and more |
| Tactics | Fork, pin, skewer, discovered attack, double check, sacrifice, attraction, deflection, overloading, promotion, zwischenzug, quiet moves, with themed puzzle sets |
| Openings | 168 opening lines and 18 classic traps. Each has a summary, key ideas, move-by-move commentary, a **study** mode, a **drill** mode (play it from memory) and "Name That Opening" quizzes |
| Strategy | Pawn structures (IQP, doubled, backward, hanging, chains, majorities), outposts, good/bad bishops, open files, the 7th rank, prophylaxis, the minority attack, two weaknesses, plans, converting, defending. Also seven famous games in "guess the move" format |
| Endgames | KQK, KRK, two rooks, two bishops, bishop + knight, the square, key squares, opposition, triangulation, the Réti manoeuvre, breakthroughs, Lucena, Philidor, wrong-colored bishop, queen vs pawn. You play these against the engine at full strength. Also "convert the win" positions taken from real games |
| Practice Workouts | 144 sets: tactics workouts and mate-in-1/2/3/4 sets, sorted by rating |

**Openings explorer.** Play moves on a board and see every book continuation, plus the named openings each one leads to.

**Puzzles.**
- Rated trainer with its own puzzle rating
- Practice by theme
- Puzzle Rush: 3 minutes, 3 strikes
- My Mistakes: positions from your own games, with spaced repetition

**Progress.** Rating history, lessons done per category, and your tactical strengths and weaknesses by theme.

There are 971 verified puzzles in all. Progress is saved in the browser (localStorage).

## Files

| File | Purpose |
| --- | --- |
| `engine.js` | Rules, move generation (perft-verified), evaluation, alpha-beta search (PVS, transposition table, null move, LMR, quiescence), and a human-like strength model by Elo. Runs in the page, in a Worker and in Node |
| `board.js` | Interactive board: click or drag, promotion picker, arrows, right-click annotations |
| `app-core.js` | Storage, engine wrapper, game model, coach explanations, ratings, PGN, openings index |
| `app.js` | All screens |
| `openings.js` | Opening library source |
| `lessons.js`, `puzzles.js` | Generated by `tools/build-lessons.js` |
| `tools/` | Generators and the build. `genpuzzles.js` and `genmates.js` play engine games and extract verified puzzles and endgame positions. `lessons-src.js` holds the hand-written curriculum. `build-lessons.js` validates every position and move and computes the solutions. `perft.js` tests move generation |

### Rebuilding the content

```bash
cd chess/tools
node perft.js
node genpuzzles.js out/p1.jsonl 200 1
node genmates.js out/m1.jsonl 200 2
node build-lessons.js out/*.jsonl
```

`build-lessons.js` prints a warning for any lesson position that does not check out: an illegal move, a "mate in N" that is really a different length, or an endgame "win" that the engine judges to be a draw.
